Interactive prototype comparing Legacy Flat 6-Tab Layout vs. Proposed 3-Tier Information Architecture

Existing Layout

Flat 6-Tab Model

Currently in ConfigurationPage.tsx, all administrative concepts are placed in a single flat tab row:

📁 Categories
🏷️ Tags
⚙️ Content Types
🗺️ Learning Paths
🎯 Interview Paths
👥 Reviewer Groups
Flat View Workspace All 6 tabs compete for attention

Taxonomy configuration (Categories, Tags), editorial packaging (Learning Paths), and security governance (Reviewer Groups) share equal visual weight.

Key Weaknesses:
  • High cognitive load: Admin must read 6 unorganized options every visit.
  • Conflates Taxonomy with Products and Security Governance.
  • Tab bar overflows or wraps awkwardly on smaller screens.
  • No logical grouping for future features.

Proposed Redesign

3-Tier Grouped IA

Reorganized into 3 distinct functional tiers grouped by administrative intent:

Tier 1: Content Model (Taxonomy & Schemas)
Tier 2: Editorial Products (Guided Content Bundles)
Tier 3: Workflow & Governance (Quality & Review)
Key Advantages:
  • Immediate mental clarity: Admin instantly navigates to intent.
  • Scalable: New features fit naturally into Tier 1, Tier 2, or Tier 3.
  • Clean desktop sidebar / tablet segmented control layout.
  • Enables deep URL routing (e.g. /configuration/content-model/categories).
